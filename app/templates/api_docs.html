Endpoints

GET /api/v1/projects

Returns all projects. Supports optional filtering by category, tag, or featured status.

Parameter Type Description
category string Filter by category. One of web, data, software.
tag string Filter by tag slug, e.g. web-app, machine-learning.
featured boolean Pass true to return only featured projects.
